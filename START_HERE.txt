eBay AI Agent — first start

Platform: macOS, Python 3.9+, Google Chrome.

1. In Terminal, run: bash START.command
2. Enter settings and your own AI API key when prompted. Secret input is hidden.
3. Open chrome://extensions → Developer mode → Load unpacked.
4. Load ONLY this installed folder (Cmd+Shift+G opens the path field):
   ~/Library/Application Support/eBay AI Listing Filler/Extension
5. Refresh your eBay draft, open the extension's Control Panel and try one draft.
6. Review every filled value. Publish manually.

Updates: run the NEW source folder's START.command, reload the installed
extension in Chrome, and refresh marketplace tabs. Do not load a second copy
from the downloaded source folder. Saved settings and Keychain secrets persist.

Settings: bash START.command --setup
Remove service: bash Tools/uninstall_backend.command
Then remove the extension in Chrome. Saved settings/keys are preserved.

The version shown by START and Backend comes from Extension/manifest.json.
The installer sets up a per-user LaunchAgent and a Native Messaging host.
API analysis may cost money; a chat subscription is not an API key.
Read README.md for installation, privacy, troubleshooting and complete removal.
